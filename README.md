A strong chess engine in at most 4,096 bytes of Python: 0x88 board, alpha-beta with quiescence, transposition table, killers, null-move pruning, late-move reductions with re-search, check extensions and a material + piece-square evaluation with bishop pair and doubled pawns. It searches a fixed node budget per move, never a clock.

## Run it

```sh
python3 -P -s main.py
```
